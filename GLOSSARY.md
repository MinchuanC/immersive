# Glossary

| Term | Meaning |
|---|---|
| Stage | The full-window listening view, centered on the current lyrics. |
| Scene | The atmospheric visual environment behind the lyrics and controls. |
| Library | The user's browsable saved music and playlists. |
| Line-synced lyrics | Lyrics whose lines have playback timestamps. |
| Word-synced lyrics | Lyrics whose individual words have genuine playback timestamps. |
| Transport | Controls for playback, progress and volume. |
| Visual preset | A saved arrangement of scene effects and their parameters. |
| Lyric style | A particular visual layout and animation treatment for the lyrics. |
| Library presentation | A layout for viewing the same underlying music collections, such as a grid, wall or 3D shelf. |
| Source capability | A behavior that a music source can actually support, such as decoded-audio analysis for local files. |
